## Introducción: 

Aqui te mostrare todos los comandos:


# 1. Comando git add -A
git add -A: Te permite mover todos los ficheros a la stage área.

# 2. Comando git rm --cached
git rm --cached: Borra el fichero que no queremos al git, pero seguirá estando en untrake.

# 3. Comando git commit --aemend
git commit --amend: Aquí puedes poner el fichero que este a fuera para poder hacerlo con el mismo commit, que no pasa nada si va separada, pero es bueno que esten juntos.

# 4. Comando git checkout
git checkout -- <archivo>: Te permite quitarlo de Workspace.

# 5. Comando deactivate
deactivate: Salir del entorno Python.

# 6. Comando Python -m pip
Python -m pip: Sirve para instalar librerías

# 7. Comando mkdocs new [carpeta]
mkdocs new projecte: Crea una carpeta llamada proyecto con los ficheros mkdocs.yml, index.md

# 8. Comando mkdocs serve
mkdocs serve: Inicas un servidor web para poder verlo desde el navegador.

# 9. Comando mkdocs build
mkdocs build: Crea una carpeta llamada SAID y dentro de esa carpeta, hay un fichero HTML y mas, crea su propia web.

# 10. Comando ss -lntp
ss -lntp: Para ver en que puerto esta escuchando nuestro servicio.

# 11. Comando Python3 -m venv .venv
Python3 -m venv -venv: Crea el entorno de trabajo

# 12. Comando source .venv/bin/activate
source .venv/bin/activate: Activa un entorno virtual de Python llamado .venv en tu terminal.

# 13. Comando git push
Git PUSH: Pasa subir los commits a GITHUB

# 14. Comando git pull
Git PULL: Es bajar todas esas modificaciones que haces en GITHUB al ordenador
