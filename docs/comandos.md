comandos:

1. git add -A: Te permite mover todos los ficheros a la stage área.
2. git rm --cached: Borra el fichero que no queremos al git, pero seguirá estando en untrake.
3. git commit --amend: Aquí puedes poner el fichero que este a fuera para poder hacerlo con el mismo commit, que no pasa nada si va separada, pero es bueno que esten juntos.
4. git checkout -- <archivo>: Te permite quitarlo de Workspace.
5. deactivate: Salir del entorno Python.
6. Python -m pip: Sirve para instalar librerías
7. mkdocs new projecte: Crea una carpeta llamada proyecto con los ficheros mkdocs.yml, index.md
8. mkdocs serve: Inicas un servidor web para poder verlo desde el navegador.
9. mkdocs build: Crea una carpeta llamada SAID y dentro de esa carpeta, hay un fichero HTML y mas, crea su propia web.
