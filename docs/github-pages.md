# Pràctica 6 - MkDocs, Material i GitHub Pages

## Objectius

En aquesta pràctica he treballat amb MkDocs per crear un lloc web estàtic a partir de documents Markdown.

Els objectius principals són:

- Crear i documentar un lloc web estàtic amb Markdown i MkDocs.
- Crear i utilitzar un entorn virtual de Python.
- Instal·lar Material for MkDocs amb `pip`.
- Configurar el tema Material amb mode clar i fosc automàtic.
- Previsualitzar i generar el lloc web.
- Publicar el lloc a GitHub Pages.
